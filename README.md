# MOYO Header Layout

Header navigation section for an e-commerce site — responsive top navigation with mobile hamburger menu, part of Mate Academy HTML + CSS Basics module.

## 🚀 Live Demo

🔗 https://kaida-iryna.github.io/layout_moyo-header/

## 🛠 Tech Stack

- HTML5 (semantic header)
- CSS3 (Flexbox)
- SCSS (Sass)
- BEM methodology

## 📚 What I learned

- Mobile-first responsive navigation
- Hamburger menu pattern (CSS-only and JS-toggled)
- Sticky header behavior
- Logo + nav + search + cart icon layout

## 🏃 Run locally

```bash
git clone https://github.com/kaida-iryna/layout_moyo-header.git
cd layout_moyo-header
# Open index.html in browser
```
